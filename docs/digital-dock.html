  • 中控业务服务：基于 Node.js / Fastify 构建核心状态机，实现订单流转控制与数据持久化。
  • 多端 HMI 界面：基于 React 与 TypeScript 开发工位触摸屏交互，负责订单呈现与人工确认。

  • PLC 控制程序：由公司自动化电气专业人员编写，本人负责网络层 SLMP 信号交互与超时保护。
